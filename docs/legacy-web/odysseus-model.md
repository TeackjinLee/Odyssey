# 오디세우스 GLB 모델 넣기

Meshy에서 만든 모델 파일을 정해진 자리에 넣으면 게임이 그 모델을 쓴다.
파일이 없거나 불러오지 못하면 지금의 도형 모델이 그대로 나온다.

## 1. 넣을 파일

| 파일 | 내용 | 없으면 |
| :--- | :--- | :--- |
| `public/assets/models/odysseus.glb` | 뼈대와 동작이 들어간 캐릭터 (무기 없음, 망토 포함) | 아래 `.fbx` |
| `public/assets/models/odysseus.fbx` | Mixamo에서 **With Skin**으로 받은 캐릭터 (지금 쓰는 것) | 도형 모델 |
| `public/assets/models/anims/<동작>.fbx` | Mixamo에서 같은 캐릭터로 **Without Skin** 받은 동작 하나씩 | 보완 자세 |
| `public/assets/models/sword.glb` | 주무기 검 (뼈대 없음, 설정 키는 `spear`) | 도형 청동 검 |
| `public/assets/models/shield.glb` | 방패 (뼈대 없음) | 도형 방패 |
| `public/assets/models/bow.glb` | 활 (뼈대 없음, 휘지 않는 고정 모델) | 도형 활 |

## 2. 모델용 그림 (정면·측면·후면 각각 한 장)

- 세 장 모두 체형·갑옷·색·비율이 같게
- 정면 기준 팔을 몸에서 약 45° 벌린 A자세, 빈손
- 창·방패·활·화살통은 모두 빼기
- 흰 배경, 발끝까지 보이는 전신, 원근감 최소(정사영에 가깝게)
- 붉은 망토는 두되 팔과 손을 가리지 않게

무기는 주신 그림에서 잘라 쓰거나 무기만 따로 그려, 각각 Meshy Image to 3D로 만든다.

## 3. Meshy에서

1. **Image to 3D**: 캐릭터 그림을 넣고(여러 장 가능) **Pose = A-Pose**로 만든다.
2. **Rig**: 사람형(Humanoid), 뼈대 템플릿은 기본값 **Mixamo** 그대로.
3. **Animate**: 동작을 검색해 추가한다. 이름에 아래 단어가 들어가면 자동으로 연결된다.
   - 꼭 필요: 대기(`idle`), 달리기(`run`)
   - 있으면 좋음: 회피(`roll`·`dodge`), 방패 막기(`block`), 활 쏘기(`bow`·`archer`)
   - 창 공격은 맞는 동작이 있을 때만 (아래 4번에서 이름을 직접 적어 줌)
4. **Download → GLB**, Animation은 **All Added**(추가한 동작 전부를 한 파일에)로 받는다.
5. 무기 세 개는 Image to 3D만 하고(리깅 안 함) GLB로 받는다.

## 3-1. Mixamo에서 (무료)

1. 캐릭터 FBX(With Skin)는 `odysseus.fbx`로 넣는다. `.glb`가 있으면 그게 먼저라 지운다.
2. 같은 캐릭터를 올린 채로 동작을 고르고 **FBX Binary, Without Skin, 30fps**로 받는다.
   달리기·걷기는 **In Place**를 켠다(꺼도 골반 앞뒤 이동은 게임이 지움).
3. 받은 파일 이름을 바꿔 `anims/`에 넣으면 그 상태에 바로 연결된다.
   `idle` 대기, `walk` 걷기, `run` 달리기, `dash` 구르기·회피, `spear1`~`spear3` 창 1~3타,
   `parry` 방패 막기, `bow` 활 쏘기. 없는 파일은 보완 자세를 쓴다.
   콤보처럼 한 파일에 여러 타가 있으면 `clipFiles`에 `{ url, from, to }`로 구간을 나눠 적는다(지금 1~3타가 이 방식).
4. 다른 캐릭터로 받은 동작(예: 기본 캐릭터 Y Bot)은 뼈 방향이 달라 꼬일 수 있다.

## 4. 넣고 확인하기

`npm run dev`로 띄운 뒤 브라우저 개발자 도구 콘솔에서 `[Odysseus GLB]` 줄을 본다.

- `원래 키 … → 2.6`: 키 맞춤
- `뼈 이름` / `찾은 뼈`: 손·팔·척추 뼈를 찾았는지. `(없음)`이면 설정의 `bones`에 실제 이름을 넣는다
- `동작 이름` / `연결한 동작`: 상태별로 어떤 동작이 붙었는지. `(없음 → 보완 자세)`는 도형 모델의 자세로 팔·상체를 움직인다는 뜻
- `spear: … 사용` / `파일이 없어 도형 무기 사용`

## 5. 맞추는 곳: `src/rendering/odysseus/avatarConfig.ts`

| 항목 | 하는 일 |
| :--- | :--- |
| `height`, `yawOffsetDeg` | 게임 안 키, 정면 방향 (Meshy는 +Z가 정면이라 보통 0) |
| `shading` | `unlit`(그림 색 그대로) / `toon` / `original` |
| `outline` | 외곽선 두께 |
| `bones` | 뼈 이름 후보 (대소문자·`mixamorig`·기호 무시) |
| `clips` | 상태별 동작 이름 후보. 창 1~3타는 비어 있으니 맞는 동작이 있으면 이름을 넣는다 |
| `walkClipSpeed`·`runClipSpeed` | In Place 걷기·달리기 1배속의 이동 속도 (아니면 골반 이동으로 자동). 발이 미끄러지면 조정 |
| `attackStance` | 창 공격 동작이 없을 때 다리 IK 디딤 자세 (앞발·뒷발 거리, 골반 낮춤) |
| `attackHitTime` | 공격 동작에서 실제로 맞는 순간(0~1). 게임의 휘두르기 구간이 이 시점에 오게 재생 |
| `weapons.*` | 붙일 뼈, 크기, 뼈 기준 위치·회전(도), 앞뒤 뒤집기 |
| `spearGrip` | 창 아래끝에서 손이 쥐는 자리 (0~1) |
| `drawBowString` | 활시위를 코드로 그려 당길지 (활 파일에 시위가 있으면 false) |

## 6. 동작 방식 요약

- 공격 판정·내딛는 거리·타이밍은 전부 게임 로직(`COMBAT_CONFIG`) 그대로다. 동작 파일의 루트 이동(골반의 앞뒤 이동)은 지운다.
- 공격·회피·막기·활 동작은 게임 상태의 진행도로 시간을 직접 맞춰 튼다(준비 → 맞는 순간 → 회복).
- 동작이 없는 상태는 다리는 대기·달리기 동작을 따르고, 상체 비틀기와 팔(IK)·무기 방향은 도형 모델 자세를 쓴다.
- 창·방패·활은 손 뼈에 붙는다. 활을 쏘는 동안 창·방패는 숨기고 활을 보인다. 시위 가운데가 오른손을 따라 당겨진다.
- 히트스톱 중에는 동작도 멈추고, 맞으면 하얗게 번쩍인다.

## 7. 확인 상태

시험용 GLB(Mixamo 이름 뼈대, cm 단위, 대기·달리기 동작)로 확인한 것:
불러오기·키 맞춤·바닥 정렬, 뼈 찾기, 동작 연결과 대기↔달리기 섞기, 루트 이동 제거,
도형 무기를 손 뼈에 붙이기, 동작 없는 공격의 팔 IK·무기 방향, 활시위 당기기, 파일이 없을 때 도형 모델로 돌아가기.

실제 Meshy 파일이 있어야 확인할 수 있는 것:
- Meshy 뼈·동작의 실제 이름 (기본값은 Mixamo 이름 기준)
- 무기 위치·회전 기본값 (손 뼈 축 방향이 모델마다 달라 실제 모델에서 맞춰야 함)
- `unlit`/`toon` 중 어느 쪽이 그림에 가까운지, 외곽선 두께
- 망토가 팔·다리를 뚫고 나오는지
- 달리기 발 미끄러짐(`runClipSpeed`), 공격 동작의 맞는 순간(`attackHitTime`)
- 활대 휨 표현 (지금은 고정 활 + 시위만 당김)
