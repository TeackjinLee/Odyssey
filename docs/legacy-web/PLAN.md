# ODYSSEY: 2.5D 액션 로그라이트 개발 계획서 (PLAN.md)

## 1. 아트 디렉션 및 8대 시나리오 통합 로드맵

사용자가 제시한 **《ODYSSEY: 귀환의 항해 — 8대 이미지 시나리오》** 의 색채(청록색 그림자, 청동·금빛 하이라이트, 고대 지중해의 닳은 장비와 문양), 구도(38° 쿼터뷰, 거대 보스와의 스케일 대비, 명확한 공격 예고와 시선의 선), 그리고 전체 항해 루프를 인게임에 완전히 구현한다.

| 씬 번호 | 시나리오 명칭 | 인게임 구현 상태 및 핵심 요소 |
| :--- | :--- | :--- |
| **Scene 1** | **메인 키아트 — “고향은 아직 수평선 너머에”** | 16:9 와이드 애니메이션 타이틀 캔버스 (전함 뱃머리의 오디세우스, 휘날리는 붉은 망토, 좌측 외눈 동굴섬·우측 세이렌 암초·중앙 금빛 이타카와 네 갈래 신성한 빛) |
| **Scene 2** | **전함 허브 — “폭풍 사이의 안식”** | 38° 쿼터뷰 전함 갑판 (중앙 해도 탁자에서 항로 선택, 따뜻한 화로에서 정비, 가장자리 4대 신의 제단 불빛 인터랙션) |
| **Scene 3** | **키클롭스의 동굴 — “눈을 뜨는 어둠”** | 석회암 동굴, 천장 빛줄기, 청록색 발광 이끼, 보라색 포자의 로토스 광신도, 주황색 원형 낙하 예고를 띄우는 키클롭스 투석병 |
| **Scene 4** | **폴리페모스 보스전 — “단 하나의 눈”** | 거대 스케일의 폴리페모스, 부채꼴 먼지·돌조각 충격파, 포효 시 빛나는 금빛 외눈 약점과 오디세우스의 청백색 차징 화살 시선(Sightline) |
| **Scene 5** | **신의 가호 — “올림포스의 선택”** | 정지된 폐허 위 3갈래 빛줄기 3지선다 가호 카드 (아테나 올빼미·방패 / 제우스 독수리·번개 / 아폴론 월계관·활 / 헤르메스 날개 샌들·바람) |
| **Scene 6** | **세이렌의 암초 — “아름다운 목소리, 위험한 바다”** | 달빛 수몰 대리석 신전(육지 통로와 물 경계 명확화), 3갈래 밝은 푸른 음파를 쏘는 세이렌 하피, 푸른 유령빛 망령 방패병, 길 끝의 청동 종 |
| **Scene 7** | **파르테노페 보스전 — “노래를 끊는 종소리”** | 수몰 원형 신전 중앙의 여왕 파르테노페(청자색 동심원 인력 음파) vs 가장자리 청동 종 타격 시 퍼져 나가는 황금색 공명 파동의 교차 연출 |
| **Scene 8** | **귀환 — “아직 끝나지 않은 항해”** | 새벽 갑판 위 손안의 청동 주화 전경과 살구색 햇살이 비치는 해도 후경, 체력·공격력·부활(최대 1회) 영구 강화 및 재출항 화면 |

## 2. 마일스톤 진행 현황

- [x] **Milestone 1 + 2**: 2.5D 쿼터뷰 코어 엔진, 화면 기준 `WASD` 이동 + 마우스 조준, 청동 창 3단 콤보, 강궁 차징 관통 및 약점 저격, `Q` 방패 패링, 60FPS 실시간 측정기 구축
- [x] **Milestone 3 ~ 5 통합 (8대 시나리오 풀 퀄리티 업그레이드)**:
  - 회화적 2D 캐릭터/보스 멀티레이어 스프라이트 아틀라스 생성기 (`ProceduralSprites.ts`)
  - 바이옴별 3D 입체 지형·조명·수면·이끼·파티클·시선(Sightline) 렌더러 (`SceneRenderer25D.ts`)
  - 8대 시나리오 전체 스테이지 전환 및 보스 2종(폴리페모스, 파르테노페) + 4신 가호 + 귀환 메타 성장 완주 루프 (`WorldSimulation.ts`, `HudController.ts`)
