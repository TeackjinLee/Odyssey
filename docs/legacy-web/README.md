# 웹 버전 문서 (보관)

루트의 `src/`·`index.html`·`public/`은 Godot로 옮기기 전의 웹 시제품(TypeScript + Three.js + Vite)이다.
더 개발하지 않고 참고용으로만 둔다. 지금 개발은 [`godot/`](../../godot/README.md)에서 한다.

| [PLAN.md](PLAN.md) | 웹 버전 마일스톤 |
| [odysseus-model.md](odysseus-model.md) | 오디세우스 3D 모델(GLB/FBX) 넣는 법 |

(폴리페모스 외눈 약점, 세이렌 음파 vs 청동 종). [`godot/docs/ART_PLAN.md`](../../godot/docs/ART_PLAN.md)에 옮겨 두었다.
