# 제3장 폴리페모스 동굴 — 배치 시안

상태: **설계·이미지 시안, 미구현**. 기존 `GAME_DESIGN.md`의 포도주 → 달군 말뚝 → 외눈 부상 → 양 밑 탈출 흐름을 배치로 구체화했다. 거인은 [크기 비교](../sprite_request/ch3_kit/SCALE.md)의 3배를 우선 검토한다. 사용자 최종 확정이나 게임 안 픽셀 배율 검증을 뜻하지 않는다.

이미지: [동굴 전체 배치](../references/environment/ch3_cyclops__cave-layout.png). 그림은 천장을 걷어낸 전체 조감도이며 실제 플레이는 고정 쿼터뷰 카메라가 주인공을 따라간다. 완성 그림을 통째로 게임 배경에 깔지 않고 타일·벽·소품·상호작용으로 나눈다.

## 번호별 구역

| 번호 | 구역 | 핵심 소품과 역할 |
|---|---|---|
| 1 | 입구·봉쇄 바위 | 거인이 굴려 닫는 바위, 밖으로 이어지는 바위 길. 탈출 전까지 플레이어가 혼자 열 수 없음 |
| 2 | 음식·포도주 보관 | 치즈·우유 항아리·바구니, 포도주 항아리. 숨을 낮은 바위와 출입구 두 곳 |
| 3 | 말뚝 준비 | 올리브 통나무·긴 나무 말뚝. 말뚝을 얻고 옮기는 장소 |
| 4 | 화덕 | 숯불·낮은 화덕·솥. 말뚝 끝을 달구며 거인 시야를 피함 |
| 5 | 중앙 대면 구역 | 곤봉·움켜잡기를 피할 넓은 바닥. 엄폐물은 가장자리, 중앙 통행은 비워 둠 |
| 6 | 거인 잠자리 | 거인이 눕는 양가죽 침상, 머리와 옆구리에 접근할 공간. 취한 뒤 말뚝을 쓰는 장소 |
| 7 | 양 우리·몰이 길 | 양과 큰 숫양, 열리는 우리 문. 입구까지 이어지는 장애물 없는 길 |

플레이 동선은 **1 → 2 → 3 → 4 → 5·6**, 마지막은 **6 → 7 → 1**이다. 중앙을 가로지르는 지름길과 바깥쪽 엄폐 우회로를 함께 둔다. 전체 경로를 강제로 순서대로 걷게 만드는 것은 아니며, 포도주와 말뚝 준비의 상세 선후관계는 구현 때 정한다.

## 사건과 맵 상태

1. 입장·탐색: 부하와 동굴을 조사한다. 거인이 돌아와 입구 바위를 닫는다. 전체 지도 이미지는 **바위가 닫힌 이후** 상태다.
2. 위협 인지: 정면 공격으로 해결되지 않음을 보여주고 음식·물건을 조사하게 한다. 거인의 시야·곤봉 위험은 회피 가능해야 한다.
3. 계략 준비: 포도주를 건네 취하게 하고 말뚝을 달군다. 「아무도 아니다」 대사는 이름 속임 장면에 넣는다.
4. 잠든 거인: 거인이 침상에 눕는다. 자동으로 머리와 접근 공간을 막지 않도록 잠자리 양옆을 비운다. 말뚝 사용은 별도 상호작용·연출로 처리한다.
5. 눈을 잃은 거인: 거인이 더듬어 출구로 이동해 바위를 밀고, 양을 내보내며 손으로 확인한다. **바위를 연 것만으로 자유 탈출되지 않도록** 거인의 출구 감시가 남는다.
6. 탈출: 우리를 열고 숫양 아래에 숨어 나온다. 부하·양의 동선이 겹쳐 입구에 영원히 걸리지 않는지 검증한다.

## 구현 전 검토

- 거인 몸의 충돌·공격 영역·외눈의 상호작용 지점을 각각 둔다. 곤봉까지 포함한 그림 사각형을 몸 충돌로 쓰지 않는다.
- 거인이 누웠을 때 차지하는 면적과 말뚝을 옮기는 인물·부하의 공간을 별도로 잡는다.
- 거인이 움직일 통로는 실제 몸 충돌보다 넓게 만든다. 양 이동로와 주인공 엄폐 길은 화덕·기둥·바구니로 막지 않는다.
- 바위의 닫힘/열림은 그림과 충돌을 동시에 갱신한다. 양 우리 문도 같은 방식이다.
- 포도주 소진·말뚝 유실·양 몰이 실패로 진행 불능이 되지 않게 회수/재시도 규칙을 둔다.
- 체크포인트 제안: 입구 봉쇄 직후 / 계략 준비 완료 / 외눈 부상 이후. 최종 저장 항목은 구현 때 정한다.

## 다음 아트 요청

1. 퍼즐 소품: 포도주 항아리, 말뚝(일반/달군 상태), 화덕, 입구 바위(닫힘/옆으로 굴림), 우리 문, 침상.
2. 동굴 타일·벽·엄폐 바위·우리 울타리·치즈·우유 항아리. 동물 양은 기존 그림을 우선 재사용하고 숨을 숫양은 크기·상호작용을 검토한다.
3. 크기·배치 검토 뒤 거인 5방향 기본 모습과 전용 동작. 이 지도에 등장한 거인 한 장으로 제작용 시트를 대체하지 않는다.
