- 칼로 거인을 치면 튕겨 나온다(거인은 `actors` 밖이라 봇·부하도 싸우지 않는다).
- 체크포인트: `cave`(첫날 밤)·`wine`(포도주)·`sleep`(거인이 잠듦)·`blind`(외눈을 찌름 — 날뛰기 시작). 검증 시작점 `--start=cave|wine|sleep|blind|escape|ending`.
- 칭호 「아무도 아닌 자」: 부하를 하나도 잃지 않음. 결과 화면에 잃은 부하·들킨 횟수.
- 2막(낮 준비)은 아직 없어, 밤이 끝나면 "다음 날 저녁"으로 건너뛰어 포도주 단계가 된다([다시 짜기 계획](CH3_REDESIGN.md) 순서 3~6이 남음).
- 영양·부하는 챕터 2에서 이어받고, 챕터 4로 넘긴다.

## 검증

```bash
godot --headless --fixed-fps 60 --path . -- --auto --chapter=3 --quit-after=480   # ending true·lost []면 클리어(약 330초)
godot --path . -- --chapter=3 --start=cave --quit-after=95                        # 가만히 있으면: 부하 하나를 잃고 잡힌다
godot --path . -- --chapter=3 --start=blind --quit-after=70                       # 날뛰기에서 가만히 있으면: 부하를 잃는다
godot --path . -- --chapter=3 --start=cave --at=18.5,15 --quit-after=8              # 거인 앞: 쫓아와 공격(체력이 준다)
godot --path . -- --chapter=3 --start=blind --at=15,6.8 --quit-after=8              # 입구 곁: 움켜잡혀 밀려남
```

## 거인 그림·무서움

- 오디세우스의 약 두 배(서 있는 키 125, 예전 157), 2배 밀도 시트(`scale` 0.5)라 화면 픽셀과 원본 픽셀이 거의 1:1이다.
- 시트(2026-11-06 받음, `sprite_request/ch3_kit/polyphemus_v2/`): 대기·걷기·포효·취함·더듬기 + 정지(감은 눈·찔린 눈)는 `polyphemus`,
  곤봉 내려치기·움켜잡기·눈 부상·바위 밀기(push)·끌기(pull)는 `polyphemus_combat`, 잠(반듯이·뒤척임)은 `polyphemus_sleep`. 5방향 받고 서쪽 셋은 뒤집음.
- 눈을 잃은 뒤에는 상처난 눈 그림(더듬기·눈 부상·끌기·잠)만 쓰고, 나머지 동작은 찔린 눈 정지 그림에 `_pose` 코드 자세를 입힌다(`BLIND_OK`).
  `_pose`는 그림이 없는 동작을 틀을 기울여(skew — 발은 땅에 붙이고 윗몸만) 낸다: 걷기 무게 옮김·디딜 때 눌림, 공격 젖힘 → 내려침 → 느린 복귀.
- 잠든 거인은 침상 기준점 + (8, -14), 찌를 눈은 발밑 + (-60, -53).
- 외눈 불빛, 땅을 울리는 발소리(가까울수록 흔들림), 쫓기 전 포효, 노리는 거인이 220 안이면 심장 소리(`roar`·`giant_step`·`heartbeat`, `gen_audio.py`).

## 남은 것

- 거인 그림을 다시 받을 때: `polyphemus_v2/jobs/`에서 해당 결과를 지우고 `./run_jobs.sh <요청>` → `python3 tools/pack_polyphemus_hd.py v2 .`.
- 오디세우스가 말뚝·항아리를 드는 동작(지금은 머리 위·옆에 작은 그림을 붙임), 숫양 전용 그림(양 그림을 키워 씀).
- 벽 이음매·울타리 문 기준점은 화면으로만 맞췄다(`cprop`의 off 값). 앞쪽 벽(x 29·y 29)은 석순만 둔다.
- 손맛: 냄새 원·시야·돌진 속도·추적 속도(`cyclops.gd` 상수). 봇은 안내(숨을 곳 표시·미끼 돌 자동)를 따라 부하를 지키므로, 사람이 해 보고 조정.
- 봇 도움: 밤에는 숨을 곳에 닿고 부하가 다 모이면 위치 사수, 포도주부터는 걷기만 하고 부하를 숨는 자리에 세운 채 트인 자리에서 옆으로 구른다(`_open_spot`), 날뛰기에서는 먼 곳으로 걷고 미끼 돌을 던지며 떨어지는 돌을 구른다(`_bot_rampage`).
- 오프닝 영상(`sprite_request/CH3_INTRO_VIDEO.md`)을 받으면 `assets/video/ch3_intro.ogv`로 넣는다.
