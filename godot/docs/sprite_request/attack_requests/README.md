# 공격 4종 이미지 요청 묶음 (직접 받기)

오디세우스 새 차림(맨머리·망토 없음)의 공격 그림을 **한 장에 여러 방향(줄)씩** 받는 요청 9개다.
방향마다 한 장씩 받으면 이미지 생성 한도가 금방 닳아서(40번 → 전부 한도에 걸림) 한 장에 묶었다.

## 받는 법 (요청 하나마다)

1. 폴더 안의 **`pose.png`와 `guide.png` 두 장을 이미지 생성 도구(ChatGPT 이미지 생성·Codex 등)에 첨부**한다. 순서는 pose → guide.
2. **`prompt.txt`의 글 전체**(또는 한꺼번에 모은 `ALL_PROMPTS.txt`에서 해당 부분)를 그대로 붙여 넣고 보낸다. (글에 두 그림이 무엇인지 설명이 들어 있다.)
3. 나온 그림이 **1536×1024**인지 본다. 아니면 비율이 같은 크기로 다시 요청하거나 그대로 `results/`에 둔다(내가 맞춰 자른다).
4. 결과를 **`results/<요청 폴더 이름>.png`**로 저장한다. 예: `results/attack1_E-SE-Sa.png`.
5. 다 받으면(일부만이어도) 알려 주면 내가 방향별로 자르고 → 시트로 묶고 → 주먹·방패 손 위치를 찍고 → 게임에서 확인한다.

## 요청 목록

| 폴더 | 동작 | 위→아래 줄(방향) | 프레임(열) | 격자 |
|---|---|---|---|---|
| `attack1_E-SE-Sa` | 가로 베기 | E · SE · S | 4 | 3줄×4열 (칸 384×341) |
| `attack1_NE-Na` | 가로 베기 | NE · N | 4 | 3줄×4열, 3번째 줄은 빈 마젠타 |
| `attack2_E-SE-Sa` | 되베기 | E · SE · S | 4 | 3줄×4열 |
| `attack2_NE-Na` | 되베기 | NE · N | 4 | 3줄×4열, 3번째 줄 비움 |
| `attack3_E-SE-Sa` | 내려찍기 | E · SE · S | 5 | 3줄×5열 |
| `attack3_NE-Na` | 내려찍기 | NE · N | 5 | 3줄×5열, 3번째 줄 비움 |
| `heavy_E-SEa` | 회전 베기 | E · SE | 6 | 2줄×6열 (칸 256×512) |
| `heavy_S-NEa` | 회전 베기 | S · NE | 6 | 2줄×6열 |
| `heavy_Na` | 회전 베기 | N | 6 | 2줄×6열, 2번째 줄 비움 |

- `guide.png`는 막대 인물이 프레임마다 어떤 자세·어느 쪽 주먹으로 치는지 보여 주는 그림이다(빨강=오른다리, 파랑=왼다리,
  굵은 짙은 빨강 팔과 큰 원=치는 오른 주먹, 파랑 팔=가슴 앞 방패 팔, 머리 위 짧은 선=가슴이 향한 쪽). 결과 그림에는 이 막대·원이 **그려지면 안 된다**.
- 줄 순서(방향)는 `prompt.txt`에 적혀 있다. 줄이 뒤섞이거나 방향이 바뀌면 그 요청만 다시 받는다.

## 결과를 볼 때 확인할 것

- 모든 칸에서 **치는 오른 주먹이 보이는가**(몸·팔에 가리지 않음), 방패 쪽 왼팔은 가슴 앞인가
- **칸마다 캐릭터 크기·머리 크기가 같은가**, 발이 줄마다 같은 땅 높이인가
- 대각선(SE·NE) 줄은 **몸 돌림이 프레임 내내 같은가**, 맨머리·망토 없음 차림이 pose.png와 같은가
- 배경은 순수 마젠타(#FF00FF)이고 칼·방패·효과선·글자가 없는가
