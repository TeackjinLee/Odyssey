# 곤봉 내려치기·움켜잡기 검수

- 두 원본 모두 6열×5줄, 1190×1322. 생성기가 요청 크기를 지키지 않았고 줄 간격도 고르지 않다(첫 줄 발 아래끝 y≈272가 명목 격자선264를 넘음). 처음 만든 균등 분할 변환은 NE3에서 칸을 넘는다며 멈췄다.
- 변환을 빈 줄 기준 자르기로 고쳤다. 모든 격자선 근처에 불투명 픽셀이 없는 빈 줄이 있었고, 경계 경고는 두 동작 모두0개다.
- 원본의 밝은 붉은 픽셀은 알파128 이상에서 곤봉1·움켜잡기0개로, 나머지는 반투명 잔여다. 변환에서 알파128 미만을 지워 어두운 바닥 위 붉은 테두리가 사라진 것을 확인했다.
- 대기 첫 프레임과 나란히 놓아 보니 몸 크기·발 바닥선(y292)이 맞는다. 곤봉3번 프레임은 곤봉이 머리 위로 분명히 올라가고, 5번은 앞쪽 바닥에 닿는다.
- 움켜잡기는 오른손 곤봉을 낮게 유지하고 왼손만 뻗는다. 다만 N(뒷면) 줄은 팔이 위쪽(먼 쪽)이 아니라 화면 오른쪽으로 뻗어, 북쪽 판정 방향과 그림이 어긋난다. 게임 적용 때 북쪽 판정을 다시 보거나 N 줄만 재요청한다.
- 판정 프레임·손 위치·서쪽 반전 좌우는 미검증으로 `review.json`에 false로 남겼다.
