# 대기·걷기 검수

- 대기4열×5방향, 걷기6열×5방향을 생성했다. 실제 원본은 둘 다887×1774로, 요청1536×2048과 다르다. 원본을 강제로 늘리지 않고 실제 크기의 비례 격자로 자른다.
- 가장자리 붉은/초록 잔여색에 대한 정리 편집을 요청했다. 중간 결과의 밝은 붉은 픽셀은 불투명 알파128이상에서는0개였으며, RGB만 보고 배경색이라고 판정하지 않았다.
- 첫 묶음에서 idle8칸·walk22칸의 불투명 경계가 셀 가장자리에 가까웠다. 칸 안의 인물 축소·여백 보정 요청을 한 뒤 다시 묶었고, 최종 `review.json`의 경계 경고는 두 동작 모두0개다.
- 8방향 가로 띠16개, 3200×2560 합본과 동작 메타데이터, 5방향 GIF2개를 출력했다. 곤봉을 낮게 들고 발을 번갈아 내딛는 걷기 프레임을 확인했다.
- 단순 격자/파일 검증은 발 미끄러짐·정확한 관절 회전·루프 마지막 프레임의 자연스러움을 보증하지 않는다. 이 항목은 게임 배치 후 검수 전이며 JSON에 false로 남겼다.
- 서쪽 반전은 자세와 프레임 순서를 유지하지만, 양가죽·곤봉 손의 해부학적 좌우는 반전된다. 눈·손·곤봉 판정 지점은 프레임별로 정해야 한다.
- 3장 게임·이동 속도·충돌·AI는 변경하지 않았다. 기존 기본 정지 시트도 덮어쓰지 않고 `motion/`에 별도 보관했다.

파일 검증: PNG격자·8방향·프레임 개수·반전 쌍·GIF프레임 수·ZIP무결성. 생성은 내장 imagegen, 분리·묶음·미리보기는 `tools/pack_polyphemus_motion.py`다.
