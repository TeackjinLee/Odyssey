# 폴리페모스 기본 모습 검수

- 원본은1536×1024 RGBA이며 위 E·SE·S, 아래 NE·N·빈 칸 순서의5방향이다. 눈이 보이는 방향에서는 외눈 하나, N에서는 얼굴이 보이지 않음을 확인했다.
- 최초 결과를 개별 PNG로 묶었을 때 밝은 배경 사각형이 남아 있었다. 내장 imagegen에 배경 제거를 다시 요청한 결과로 교체했다. 다시 묶은 정면 PNG에서 밝은 사각형이 사라진 것을 확인했다.
- 방향별 원본5개, 반전 포함 게임 크기8개, 세로 시트·메타데이터를 출력했다. 320×320칸, 기준점159.5·292, 높이 목표156px, scale1이다. 실제 불투명 중심 높이는 반올림으로 약156~157px다.
- 좌우 반전 쌍(SW/SE, W/E, NW/NE)이 동일한 반전 이미지인지 파일 검사를 했다. 단, 반전된 몸의 비대칭 부위·곤봉 손은 해부학적 좌우가 바뀐다.
- 동굴 맵·거인AI·공격/외눈 판정에 아직 연결하지 않았다. 약3배는52px 주인공이라는 기획값 기준이며 플레이 장비·카메라에서의 실측 확정이 아니다.
- SE가 정면 쪽으로 조금 돌아 있고, 원본의 방향별 가로 중심도 조금 다르다. 후속 애니메이션을 받기 전 캐릭터 중심·발바닥·눈/손/곤봉의 방향별 기준점을 정한다.

게임 코드 변경은 없으며 이번 검증은 이미지·격자·반전·묶음 형식에 한정한다. idle은 숨쉬기 동작이 아닌 정지1프레임이다.
