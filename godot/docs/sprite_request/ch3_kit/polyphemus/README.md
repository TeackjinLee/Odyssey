# 폴리페모스 기본 방향 스프라이트

중앙에 황금빛 외눈 하나, 짙은 곱슬머리·수염, 양가죽 어깨걸이·가죽 치마·밧줄 허리띠·나무 곤봉을 유지한 기본 모습이다. [3배 크기 검토안](../SCALE.md)을 기준으로 내장 imagegen으로 생성했다. 요청 원문은 `prompt.txt`, 참조는 `docs/references/characters/C3-POL__scale-comparison.png`다.

첫 출력의 몸 주변 밝은 배경 잔여를 발견해 배경 제거를 다시 요청했다. 후속 요청은 `refinement.txt`에 보관했다. 투명도는 방향별 PNG를 실제 바닥 위에 올려 추가 검수해야 한다.

[원본 시트](results/polyphemus_base.png) · [PNG·8방향 시트 ZIP](polyphemus_base_sprites.zip)

## 배치

원본1536×1024, 3열×2행, 칸512×512.

| 행 | 1열 | 2열 | 3열 |
|---|---|---|---|
| 위 | E 동쪽 | SE 남동쪽 | S 정면 |
| 아래 | NE 북동쪽 | N 뒷면 | 빈 투명 칸 |

서쪽3방향(SW·W·NW)은 SE·E·NE를 좌우 반전했다. 뒤집으면 양가죽·흉터·곤봉의 해부학적 좌우도 바뀌므로, 이후 손·곤봉 판정 지점을 방향별로 정해야 한다. 좌우 비대칭을 엄격히 유지하려면 서쪽 방향을 별도로 그려야 한다.

## 출력

- `sprites/directions/`: 원본에서 나눈512×512 방향별PNG5개.
- `sprites/game/`: 320×320 방향별PNG8개, `polyphemus.png`(320×2560), `polyphemus.json`.
- 게임 시트 순서: E·SE·S·SW·W·NW·N·NE(한 줄에 한 방향, 프레임1개).
- 초기 기준점: `(159.5,292)`, `scale=1`. 상하 크기는 원본 높이 중앙값을 약156px로 맞춘다. 3배는 기획상52px 주인공 기준이고 현재 장비/볏 포함 실측과는 다를 수 있다.
- `sprites/review.json`: 원본 불투명 경계·공통 배율·반전 출처, 검수 대기 상태.

다시 묶기(저장소 루트):

```bash
python3 godot/tools/pack_polyphemus_base.py godot/docs/sprite_request/ch3_kit/polyphemus/results/polyphemus_base.png godot/docs/sprite_request/ch3_kit/polyphemus/sprites
```

알파와 색을 유지하고 nearest로 축소했다. 미세한 배경 픽셀이 실루엣 전체로 인식되지 않게 경계 검출에만 알파128을 사용한다. 아래 여섯 번째 칸에 불투명 그림이 있거나 셀 경계에서 잘릴 경우 변환을 중단한다.

## 적용 범위

이번 시트의 `idle`은 정지1프레임이며 숨쉬기 애니메이션이 아니다. 포효·취함·눈 부상·잠듦은 아직 없다. 게임의 거인AI·몸 충돌·외눈·손·곤봉 상호작용은 미구현이라 `assets/sprites/`에 자동 등록하지 않는다.

후속 작업으로 [대기4·걷기6프레임 후보](motion/README.md)를 별도 제작했고, 이어 [곤봉 내려치기·움켜잡기 후보](combat/README.md)도 만들었다. 이 기본 원본·정지 시트는 유지하며, 동작 결과와 게임 적용 완료를 구분한다.

원본은 방향마다 발 높이·몸 가로 중심이 조금 달라, 공통 배율과 하단 기준을 맞춘 뒤에도 실제 발바닥·몸 중심 확인이 필요하다. SE는 정면에 가까운 각도로 그려져, 후속 애니메이션 기준으로 쓰기 전 기획 카메라와 맞는지 검토한다.

다음 동작 우선순위는 대기·걷기 → 곤봉 내려치기·움켜잡기 → 취함·잠듦 → 눈 부상·출구 감시다. 지도에 같은 거인을 복제해 등장인물을 늘리지 않으며 기본 모습은 한 인물의 회전 시트다.
