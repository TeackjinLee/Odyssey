# 동굴 환경 후보 검수

- 바닥·구조물 원본 모두 1536×1024 RGBA로 확인했다. 구조물 최초 결과에는 흰 배경의 알파가 157 이상 남아 있어 사용하지 않고, 내장 imagegen으로 배경 제거를 다시 요청한 결과를 사용했다.
- 최종 두 원본에는 알파 0이 있다. 코드에서는 배경을 지우거나 알파를 일괄 보정하지 않고, 불투명 중심부로 크롭 범위를 찾은 뒤 원래 RGBA를 유지했다. 미세한 반투명 픽셀은 남을 수 있으므로 실제 바닥 위 합성 검수가 필요하다.
- 바닥 개별12개는 모두64×32, 아틀라스는256×96이다. 구조물 개별12개도 비어 있지 않은 RGBA이며 메타데이터 크기와 같다.
- 벽4종은64×59, 모서리2종은96×82, 엄폐 바위56×28, 석순44px폭, 울타리2종은64×57, 치즈 선반52×48로 출력했다. 높이는 생성 실루엣에서 계산한 초깃값이다.
- 바닥 아틀라스·벽NE·울타리NE 개별 이미지를 확인했다. 짚 바닥은 짚 양이 적어 돌바닥과 구분이 약할 수 있다. 필요하면 변형을 늘리기보다 짚 분포를 보정한다.
- 벽은 여러 바위가 이어진 긴 형태라,64px로 줄였을 때 기존64×32칸 한 변과 실제 접점이 맞는지는 아직 검증하지 않았다. 모서리와 직선 벽을 자동으로 붙여 완성 맵이라고 처리하지 않는다.
- 바닥의 완전 무봉제·전환 타일·벽 연결·우리 문 연결·충돌·가림은 미검증이다. `environment.json`의 관련 상태는 false/candidate로 남겼다. 기존1·2장 게임 파일과 환경은 변경하지 않았다.

포장물: 전체 원본2장, 개별PNG24개, 바닥 아틀라스1개, 메타데이터1개. 생성 요청과 투명도 후속 편집 문구는 각 요청 폴더에 보관했다.
