# 소품 스프라이트 검수

- 원본 1536×1024 RGBA, 12칸을 확인했다. 배경에 실제 알파 0이 있으며 단순 배경색 사진이 아니다.
- 투명도 후속 편집을 요청했다. 생성 알파는 최대 254(일부 253)이며 미세한 반투명 픽셀이 남는다. 이를 일괄 255로 바꾸지 않고 보존했다. 어두운 동굴 바닥에 올릴 때 번짐이 보이는지는 게임 화면 검수가 필요하다.
- 개별 PNG 12개를 분리했다. 셀 경계의 불투명 중심부 잘림은 없고, 5개 상태 쌍은 출력 크기·기준점이 동일하다. 이것은 생성 그림의 문 기둥이나 접지점이 픽셀 단위로 완전히 같다는 뜻은 아니다.
- 항아리 26×34, 말뚝 104×71, 화덕 88×56, 바위 112×106, 문 112×92, 침상 168×97, 곤봉 88×57로 축소했다. 제작 기준은 주인공 약52px·거인 약156px이며 실제 플레이 화면에서 조정한다.
- 문 두 상태의 기둥 간격·바닥 접지, 바위 두 상태의 위치는 챕터3에 배치하면서 확인한다. 문 경첩·화덕 열원·말뚝 잡는 점은 별도 좌표가 필요하다.
- `sprites/props.json`은 후보 메타데이터이며 게임에서 자동으로 읽지 않는다. 3장 구현 전이므로 기존 1·2장에 넣거나 검증 완료로 표시하지 않았다.

확인한 항목: 파일 개수·RGBA·실제 크기·상태 쌍 동일 크기/기준점·자르기 도구 실행·개별 항아리/문/말뚝 시각 확인. 이번 변경은 기존 게임 스크립트를 바꾸지 않는다.
