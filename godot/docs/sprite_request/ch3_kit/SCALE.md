# 폴리페모스 크기·실루엣 시안

첫 작업: 오디세우스와 거인의 상대 크기를 정한다. 현재 기획의 주인공 약 52 논리 px, 거인 약 150px를 출발점으로 삼았다. 실제 시트의 볏 포함 높이와는 다를 수 있으며, 아래 값은 게임 적용 전 비교 목표다.

시안은 같은 오디세우스·거인·카메라·동굴 구도를 반복한다. 위쪽은 전신 크기, 아래쪽은 게임 화면 점유율을 비교한다. 생성 이미지에 적힌 비율은 연출 목표이며 정확한 픽셀 치수 검증을 통과한 제작용 시트가 아니다.

## 실루엣 제안

- 중앙에 큰 황금빛 외눈 하나, 거친 곱슬머리·수염, 넓은 몸통·굵은 팔·큰 손발.
- 양치기라는 이야기에 맞춰 양가죽 어깨걸이·가죽 치마·밧줄 허리띠·나무 곤봉. 주인공의 청동 갑옷·붉은 볏과 구분한다.
- 눈은 상호작용 목표로 읽혀야 한다. 거인의 힘을 보여주는 손과 곤봉도 작은 화면에서 구분돼야 한다.
- 정면에서 체력을 깎아 쓰러뜨리는 전투가 아니라 포도주·달군 말뚝·양 밑 탈출로 해결하는 보스다.

## 권장 다음 순서

1. 3배를 우선 검토하되, 동굴 배치 시안에서 천장·입구 바위·양·플레이어 동선을 함께 확인한다.
2. 크기·디자인을 정하면 5방향 기본 모습부터 받는다. 좌우 세 방향은 뒤집는다.
3. 눈·손·몸통·곤봉의 기준점과 충돌/상호작용 영역을 정한다. 곤봉까지 포함한 그림 사각형 전체를 몸 충돌로 쓰지 않는다.
4. 대기·걷기·내리치기·움켜잡기·포효·취함·눈 부상·잠듦을 별도 동작으로 요청한다. 포도주를 받는 장면과 거인이 엎드려 자는 면적도 고려한다.
