데이포보스는 검·방패 보스 판정에 맞춰 **검을 유지**하고 검은 가로 볏·사자 방패·보라색 비늘 갑옷으로 차별화한다. 새 디자인은 제안 후보이며 채택·게임 적용 완료가 아니다.
노꾼은 배·노·벤치를 그리지 않고 양손과 몸통만 움직인다. 게임이 그리는 노와 동기화해야 하므로, 앉아서 먹는 기존 동작을 덮어쓰지 않는다.

## 수령 후 필요한 연결

- 왕자: 기본 시트뿐 아니라 walk·run·attack1/2/3·heavy·block·hit·death 동작이 필요하다. 기본 그림만 즉시 적용하면 기존 아게노르의 전용 동작이 사라지므로, 디자인을 확인한 뒤 `ch1_kit/units/make_motion.py`와 같은 규격으로 후속 동작을 받는다. 시트 이름은 `trojan_prince`로 별도 보관하고 `Enemy.KINDS`·초상화를 함께 연결한다.
- 노 젓기: 4열×5행(E·SE·S·NE·N), 셀 384×204, 마지막 4px 비움. 서쪽은 좌우 반전. 프레임 순서는 뻗기→당기기→최대 당김→복귀. `gen_ship_crew.py`에 전용 row 동작을 등록하고, `ship.gd`에서 임의 시간 재생 대신 노의 위상에 프레임을 맞춘다. 전사·창병·궁병의 지상 앉기 동작은 유지한다.
- 모든 결과는 크기·방향·손 위치·배경을 확인한 뒤 검수 통과본만 `assets/source/`에 무손실로 저장한다. 후보 파일은 `results/`에 남긴다.

## 추가 수령보다 먼저 할 것

1. 로토스·항구 소품은 **이미 후보가 있음**. 단색 배경 보정과 축소·기준점 검수 후 연결한다([검수 기록](../next_batch_2026-11-05/REVIEW.md)).
2. 무장 오디세우스 돌 던지기도 **후보가 있음**. NE/N 자세 보정 뒤 애니메이션 재생을 연결한다. 새로 전체 묶음을 생성하지 않는다.
3. HUD 틀·커서·칭호·상태 아이콘은 **받아 둔 상태**다. 기능에 맞는 잘라내기·표시 코드 작업이 우선이다([적용 기록](../APPLIED_2026-11-05.md)).
4. 키코네스 기병은 말·승마 동작이 없지만 현재 전사장이 보병으로 작동한다. 말 그림 한 장만 추가하면 충돌·공격 거리·말과 사람의 방향이 맞지 않으므로 기마 전투 규격 결정 후 요청한다.
5. 폴리페모스·키르케·세이렌 등 3장 이후 인물은 아직 해당 챕터 구현 전이다. 지금 대량 생성하지 않는다. 항해복 전체 동작도 5장 준비 시점에 받는다.
