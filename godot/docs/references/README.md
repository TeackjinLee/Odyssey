# 참고 이미지

직접 모은 참고 이미지를 두는 곳. 여기 있는 그림은 **게임에 들어가지 않는다**(`docs/`는 `.gdignore`로 Godot가 무시).
쓰는 곳은 두 가지다.

1. 이미지 생성기에 프롬프트와 같이 첨부 → [../sprite_request/README.md](../sprite_request/README.md) §요청 방식 ②의 3번
2. Claude에게 "references/… 보고 프롬프트 써 줘 / 설명 고쳐 줘"라고 부탁

## 폴더

| 폴더 | 넣을 것 | 예 |
|---|---|---|
| `characters/` | 인물 생김새·옷·투구·무기·색 | 코린트식 투구 사진, 트로이 병사 그림 |
| `environment/` | 건물·지형·소품·타일 | 동굴 지형, 갤리선, 이타카 궁전 |
| `mood/` | 챕터 분위기·색감·조명 | 불타는 밤 도시, 안개 바다 |
| `motion/` | 동작·포즈 (영상 캡처, 포즈 스케치) | 구르기 동작, 활 쏘는 자세 |
| `ui/` | HUD·아이콘·글꼴·틀 | 좋아하는 게임 UI 화면 |
| `fx/` | 이펙트 | 타격 불꽃, 마법 |

## 파일 이름

`<대상>__<볼 점>.<확장자>` — 대상은 [../ART_PLAN.md](../ART_PLAN.md)의 ID나 챕터 이름, 볼 점은 짧은 영어/한글.

- `C-TRO-sword__helmet-crest.jpg` — 트로이 검병의 투구 볏 모양
- `ch3_cave__lighting.png` — 챕터 3 동굴 조명
- `C-ODY-dodge__roll-pose.gif` — 오디세우스 구르기 동작

## 넣고 나서

[INDEX.md](INDEX.md)에 한 줄 적는다(무엇을 참고할지 적어 두면 생성기에 넘길 문장을 바로 만들 수 있다).
Claude 세션에서 이미지를 대화창에 바로 올려도 된다 — Claude가 알맞은 폴더에 저장하고 INDEX에 적는다.

## 주의

- 남의 그림은 **참고만** 한다. 생성기에 "이 그림을 그대로 따라 그려"라고 하지 않는다 — 모양·색·분위기 중 무엇을 볼지 집어서 말한다
- 다른 게임의 캐릭터·화면을 그대로 옮기지 않는다
- 큰 영상 파일은 넣지 말고 장면을 캡처한 그림으로 넣는다
