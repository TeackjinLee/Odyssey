# ODYSSEY — 게임 기획

## 1. 개요

- **장르**: 2.5D 쿼터뷰 액션 RPG + 부하 지휘 + 탐험 (싱글)
- **엔진**: Godot 4 (2D, TileMapLayer 아이소메트릭 + y-sort)
- **그래픽**: 2D 픽셀아트 스프라이트, 2:1 아이소메트릭(약 30° 내려다봄), 원근 없음
- **이야기**: 트로이 전쟁 직후부터 이타카 귀환까지, 《오디세이아》의 6개 사건
- **핵심 재미**: 직접 싸우는 손맛 + 부하를 부려 이기는 지휘 + 챕터마다 다른 놀이(전투·항해·퍼즐·잠입)

## 2. 화면과 카메라 (모든 챕터 공통)

- 고정 쿼터뷰. 카메라는 오디세우스를 부드럽게 따라가고 회전하지 않는다
- 기준 해상도 640×360을 정수배로 키움(1280×720 = 2배). 글자만 화면 해상도로 선명하게
- 캐릭터 키 약 52px(바닥 마름모 64×32 기준), 건물 벽 높이 약 34~48px — 챕터마다 비율 고정 (크기 규격: [ART_PLAN.md](ART_PLAN.md) §2)
- 인물은 발 위치, 소품은 발자국 중심으로 깊이 정렬. 앞을 가리는 건물은 반투명
- 밤·동굴은 어두운 화면색(CanvasModulate) + 횃불·불길 점광원

## 3. 오디세우스

- 외형 고정: 치비(약 3등신), 곱슬 짙은 머리·짧은 수염, 청동 흉갑·진홍 천 앞자락. 몸 옷 + 머리 장식(코린트 투구) + 망토 세 겹으로 입히고,
  몸 옷은 전투 갑옷(챕터 1·3·4)·항해복(2·5)·거지 변장(6) 세 벌. 어떤 옷이든 진홍 포인트를 남긴다 — [OUTFIT.md](sprite_request/OUTFIT.md)
- 무기: 검(3연타·강공격·방패) ↔ 활(당겨 쏘기). 스킬: 전투의 함성(R), 미끼 던지기(C)
- 부대 특수 명령(5): 병과마다 기술 하나 — 검병 방패벽 · 창병 창 던지기 · 궁병 일제 사격(쿨타임 공유)
- 기술 성장 계획(챕터마다 이야기 사건이 기술이 됨): 1 미끼·(그림자 연격) → 2 방패 강타 → 3 불붙인 말뚝 → 4 몰리 약초(마법 면역)
  → 5 밀랍(부대가 노래에 안 홀림) → 6 오디세우스의 활(한 줄 관통). 부하는 이름마다 특성(에우릴로코스 도발 등)과 패링 연계 공격을 나중에
- 수치: 체력 140, 스태미나 100(달리기·구르기·강공격·방패로 막을 때 소모)
- 애니메이션(8방향): 대기·걷기·달리기·검 3연타·강공격·방패·활·피격·구르기·사망·상호작용

### 조작감 원칙

- 공격은 짧은 준비 → 판정 → 후딜. 맞히면 히트스톱(0.05~0.11초), 3타·강공격만 화면 흔들림
- 공격 중 누른 입력은 0.4초 기억해 다음 타로 잇고, 후딜은 구르기로 끊을 수 있다
- 막기 시작 0.2초는 패링 → 상대 경직. 강공격은 막기를 뚫는다
- 동시에 오디세우스를 근접 공격하는 적은 2명까지(나머지는 둘레를 돌며 기회를 봄)

### 영양 (모든 챕터)

- 먹은 것은 탄수화물(체력 회복)·단백질(힘 = 공격력)·지방(둘이 먼저 떨어지지 않게 대신 탐, 60 넘으면 느려짐)으로 쌓인다.
  음식은 식물 채집(탄수화물 + 지방)과 동물·물고기 사냥(단백질 + 지방). 100을 넘게 먹으면 넘친 몫이 지방이 된다.
- 규칙·수치·음식 표·챕터마다 쓰는 법: [NUTRITION.md](NUTRITION.md)

## 4. 부하 시스템

- 기본 3~5명. 역할: **검병**(방패, 앞에서 막음) · **창병**(방패병 뒤에서 긴 창) · **궁병**(거리 유지)
- 진형: 넓은 곳은 V자, 진형 자리가 막히면 오디세우스가 지나온 길을 따라 한 줄
- 길찾기: 직선이 막히면 격자 A*, 인물끼리는 밀어내기로 겹침 방지
- 명령: 1 따라오기 · 2 위치 사수 · 3 집중 공격(마우스 근처 적) · 4 후퇴·집결(2.5초간 싸움 중단)
- 쓰러짐: 체력 0이면 죽지 않고 쓰러짐 → 오디세우스가 E 길게(1.2초)로 일으킴
- 이후 챕터: 부하 이름·성장, 잃은 부하는 영영 돌아오지 않는 선택(오디세이아의 비극성)

## 5. 전투 공통

- 실시간 근접 판정은 부채꼴(화면 좌표, 위아래 1.25배 보정), 화살은 투사체
- 적 AI: 대기/순찰 → 발견(주변 동료에게 알림) → 추적 → 공격 예고(붉게 깜빡임) → 공격 → 회복.
  방패병은 상대가 휘두르면 막고, 궁수는 거리를 벌리며, 체력이 낮으면 잠깐 물러남
- 보스: 경직 저항(강공격·패링에만 경직), 고유 패턴, 화면 위 보스 체력바
- 회복: 5초간 맞지 않으면 초당 최대 체력 4%, 전투의 함성 +20

## 6. UI

- 좌상단 초상화·체력·스태미나 / 그 아래 부대 상태(체력·교전·쓰러짐) / 퀘스트 목표
- 우상단 원형 미니맵(벽·인물·목표 깜빡임) / 하단 무기·스킬 슬롯과 쿨타임
- 적 머리 위 체력바(맞았을 때만) / 보스전 상단 체력바 / 상호작용 표시 [E]
- 대화창(진행 중엔 게임 멈춤), 챕터 제목, F1 조작법
- 사망 화면: 체크포인트에서 다시 · 처음부터 · 타이틀로. 클리어 화면: 시간·처치(조용히)·들킨 횟수·경보·부하가 쓰러진 횟수·
  체크포인트에서 다시 한 횟수·골라서 하는 목표, 경보 없이 끝내면 칭호(한 번도 안 들키면 「보이지 않는 자」, 경보만 없으면 「밤의 그림자」)

## 7. 챕터

### CHAPTER 1 — 트로이의 목마 (구현됨)

- 배경: 밤, 불타는 트로이. 목마 광장 → 세 갈래 길(횃불 대로·어두운 뒷골목·짐더미 시장) → 북쪽 가로 → 성문 광장 (35×50칸, 8~12분)
  - 맵 개편안(분수 광장·불타는 구역·신전 언덕·항구, 42×50): [maps/CH1_TROY.md](maps/CH1_TROY.md)
- 흐름: 튜토리얼(목마 광장 연습: 조용히 처치 → 횃불 끄기 → 활) → 혼자 몰래 북쪽 가로까지 가서 횃불로 신호 → 부하 합류
  → 경비대(수비대장 아게노르) 처치 → 권양기를 누르고 있는 동안 성문이 올라감(부하에게 위치 사수를 시켜 지킴)
  → **아카이아 대군 입성**(28명이 줄지어 들어오고 불이 도시로 번짐) → 트로이군의 대규모 반격 4파를 막으며 거점 사수
  → 왕자 데이포보스 처치 → 트로이 함락
- 튜토리얼 원칙: 한 번에 하나만, 해 보면 ✓로 넘어감, 처음 겪는 순간에 띄운다(미리 다 설명하지 않는다). 연습 보초는 들켜도 경보가 없다
- 잠입: 앞쪽 70° 시야(밝은 곳일수록 멀리 봄), "?" 의심, 뒤에서 조용히 처치, 알아채기 전 화살 한 발, 횃불 끄기(순찰병이 다시 켬).
  들키면 경보병이 종으로 뛰고, 울리면 성문 경비 +2 (게임 오버는 없음)
- 골라서 하는 목표: 바다 문 밖 부두에 묶인 정찰병 구출(부하 +1), 무기고 불태우기(마지막 반격에 궁수 없음)
- 아게노르: 3연타 → 패링되는 내려찍기(2초 무방비). 체력 절반 이하면 방패로 밀쳐낸 뒤 뿔나팔로 검병 둘, 방패 돌진(옆으로 피함, 벽에 박히면 무방비)
- 반격 3파: 방패벽(강공격으로 부숨) → 짐더미 위 궁수 → 권양기로 달려가 성문을 닫는 돌격병
- 체크포인트: 잠입 시작 · 부하 합류 · 권양기 앞 (골라서 하는 목표는 죽어도 유지)
- 놀이: 빛과 그림자 잠입, 들켰을 때의 수습(경보병 추격), 지휘하며 지키기, 패턴을 읽는 보스전

### CHAPTER 2 — 귀환의 시작

- 배경: 에게해, 항구, 갤리선. 이스마로스(키코네스족) 약탈의 대가
- 놀이: **항해 모드**(배를 직접 조종, 바람·파도·암초·적 함선, 노 젓기·돛 조작 연출) ↔ 섬 상륙 시 지상 모드
- 흐름(기반 구현됨, [maps/CH2_ISMAROS.md](maps/CH2_ISMAROS.md)): 항해(노 단계·돛·바람·암초) → 이스마로스 상륙 → 곡식 창고 약탈(사냥·채집, 배 식량 창고에 넣기)
  → 새벽 키코네스 반격(해안 양쪽 → 내륙, 전사장 보스) → 배 띄우기(4초, 맞으면 끊김 — 멀리 쓰러진 부하는 두고 감) → 제우스의 북풍 속 키코네스 배 추격(갑판 사격·들이받기)
  → 폭풍에 여러 날 밀려 로토스 섬 → 정찰 보낸 부하 둘이 로토스를 먹고 고향을 잊음 → 붙잡아 끌고 와 배에 묶고 출항(열매 곁에 오래 둔 부하도 끌려감)
- 영양: 챕터 1 끝 값·살아 나온 부하를 이어받고, 배의 식량 창고를 항해 하루마다 부하가 먹는다(NUTRITION §7)
- 폭풍: 비·번개 속 32초 버티기 — 파도는 바람 쪽에서 오니 뱃머리·고물로 받는다(옆구리는 큰 피해), 펴 둔 돛은 찢어진다
- 남은 것: 항해 사이 해도 화면, 적 배 올라타기, 로토스 섬 그림
- 구현 메모: 배는 Actor가 아닌 `Ship`(격자 공간에서 관성 이동 → Iso로 그림), 바다는 챕터 1의 물 셰이더, 상륙은 같은 맵 안에서 지상 모드 전환(씬 전환 없음)

### CHAPTER 3 — 외눈박이 거인 폴리페모스

- 배경: 어두운 동굴, 양 떼, 나무 우리, 횃불
- 놀이: 정면으로 못 이기는 거대 보스 → 포도주로 취하게 하기, 달군 말뚝으로 눈 찌르기(지형·물건 퍼즐 전투),
  "아무도 아니다(우티스)" 속임 연출, 양 배 밑에 숨어 탈출(잠입)
- 구현 메모: 거인 시야 원뿔, 양 떼 무리 AI, 상호작용 물건(포도주 통·말뚝·바위)

### CHAPTER 4 — 마녀 키르케의 섬

- 배경: 신비로운 숲, 궁전, 마법진, 돼지로 변한 부하들
- 놀이: 부하가 돼지가 되어 지휘 불가 → 헤르메스의 약초 몰리 찾기(수집), 상태이상 해제 퍼즐,
  마법 생물 전투, 키르케와 대면 이벤트(약초가 있으면 마법이 통하지 않음)

### CHAPTER 5 — 세이렌의 유혹

- 배경: 거친 바다, 안개, 암초, 세이렌의 절벽
- 놀이: 출항 전 준비 퍼즐(선원 귀를 밀랍으로 막기, 오디세우스를 돛대에 묶기) → 해류·암초를 피하는 항해.
  노래가 들리는 동안 조작이 끌려가고, 밀랍을 안 막은 선원은 노를 놓음

### CHAPTER 6 — 이타카의 귀환

- 배경: 이타카 왕궁, 기둥과 넓은 돌바닥 광장
- 놀이: 거지로 변장해 잠입 → 활 시합 이벤트(도끼 12개 구멍 꿰뚫기, 활 조준 미니게임) →
  구혼자들과 마지막 다수 전투(텔레마코스·충직한 하인이 부하로 합류) → 페넬로페와 재회 엔딩

## 9. 지킬 것

- 2D 스프라이트 2.5D 쿼터뷰 유지. 캐릭터 뒤에 붙는 3D 카메라 금지
- 레퍼런스 그림을 배경 이미지로 쓰지 않는다 — 모든 맵은 타일·소품으로 걸어다닐 수 있게
- 부하는 장식이 아니라 실제로 이동하고 싸운다
- 오디세우스의 얼굴·체형은 모든 챕터에서 같다 (옷은 OUTFIT.md의 세 벌 중 챕터에 맞는 것)
- 캐릭터·배경·UI·이펙트는 따로 바꿀 수 있게 나눈다
