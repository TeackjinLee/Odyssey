## 지금 위치 (2026-11-04)

- 챕터 1(트로이의 목마)을 처음부터 끝까지 플레이할 수 있다: 35×50칸 맵, **잠입 → 신호 → 부하 합류 → 2페이즈 보스 → 권양기 → 거점 사수**,
  골라서 하는 목표 2개, 체크포인트 3곳, 클리어 결과·칭호, 키보드만으로도 조작. 봇(`--auto`, `--auto=stealth`)이 클리어까지 검증한다.
- 오디세우스는 **치비 새 차림**(맨머리·망토 없음)으로 바꾸는 중: 기본 8방향·걷기 12프레임·달리기 12프레임은 받아 넣었다.
  공격 4종은 요청 9개를 만들어 두었고(게임엔 아직 옛 망토 그림), 나머지 7동작은 요청 14개를 만들어 두었다.

- 병사 7종은 그려 받아 시트화함. 시논·무기·이펙트·UI 아이콘·부하 초상화는 생성기 임시 그림.
- 영양(탄·단·지)·채집·사냥·낚시가 챕터 1에 들어감 ([NUTRITION.md](NUTRITION.md)).
- **챕터 2 기반**: 항해 모드(배·바람·돛·노 단계·암초·들이받기·적 배)와 이스마로스 상륙 → 약탈 → 반격 → 배 띄우기 → 탈출 →
  폭풍 → 로토스 섬(고향을 잊은 부하를 끌고 와 출항)을 끝까지 할 수 있다. 챕터 1 끝의 영양·부하를 이어받고, 배의 식량 창고·부하 배부름이 돈다. 배·키코네스는 임시 그림([maps/CH2_ISMAROS.md](maps/CH2_ISMAROS.md)).

## 일하는 방식

- 한 기능 = 한 커밋. 커밋 메시지는 한국어 `feat : …`/`fix : …`/`docs : …`
- 변경마다 `--auto --quit-after=220`과 `--auto=stealth --quit-after=300`이 클리어되는지 본다
- 그림 받기 흐름은 [ART_PLAN.md](ART_PLAN.md) §3. 이미지 생성 한도 때문에 한 장에 여러 방향을 받고, 후보는 1장씩
- 끝나면 이 문서의 체크박스·"지금 위치", ART_PLAN의 상태, README를 같이 고친다
