## 지금 위치 (2026-11-03)

- 챕터 1(트로이의 목마)을 처음부터 끝까지 플레이할 수 있다: 35×50칸 맵, **잠입 → 신호 → 부하 합류 → 2페이즈 보스 → 권양기 → 거점 사수**,

## 일하는 방식

- 한 기능 = 한 커밋. 커밋 메시지는 한국어 `feat : …`/`fix : …`/`docs : …`
- 변경마다 `--auto --quit-after=220`과 `--auto=stealth --quit-after=300`이 클리어되는지 본다
- 그림 받기 흐름은 [ART_PLAN.md](ART_PLAN.md) §3. 이미지 생성 한도 때문에 한 장에 여러 방향을 받고, 후보는 1장씩
- 끝나면 이 문서의 체크박스·"지금 위치", ART_PLAN의 상태, README를 같이 고친다

|---|---|

| 이미지 생성 한도 | 한 장에 여러 방향(줄), 후보 1장씩, 10개 안팎으로 나눠 받기 (motion_kit/README.md) |

| 6챕터는 혼자 하기에 큼 | 챕터 1 데모(M3)를 먼저 완성해 반응을 보고 범위를 다시 정한다 |
| 거대 보스·배 그림 양 | 방향 5개 + 좌우 뒤집기, 몸을 부위로 나눠 움직임 |
